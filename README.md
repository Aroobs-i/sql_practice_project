# SQL Practice Project

A PostgreSQL project focused on analyzing financial transactions and fraud patterns using the PaySim synthetic financial dataset.

## Dataset

**PaySim – Synthetic Financial Datasets for Fraud Detection**

- Source: https://www.kaggle.com/datasets/ealaxi/paysim1
- Database: PostgreSQL

## Topics Covered

- Complex SQL queries
- CTEs and subqueries
- Window functions
- Recursive queries
- Transaction paths
- Fraud detection
- Rolling calculations
- Large transaction analysis
